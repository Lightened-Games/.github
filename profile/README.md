# Games

Small, complete games made in **Unreal Engine 5.8**, with all gameplay written in C++. Each one is a single 90-second run built around one unusual rule.

| | Game | The rule |
|---|---|---|
| <img src="https://raw.githubusercontent.com/Lightened-Games/NoSkating/main/media/shot1.jpg" width="240"> | [**No Skating**](https://github.com/Lightened-Games/NoSkating) | You're the security guard, and every prop you drag into a skater's way becomes their next ramp. |
| <img src="https://raw.githubusercontent.com/Lightened-Games/GrainByGrain/main/media/shot1.jpg" width="240"> | [**Grain by Grain**](https://github.com/Lightened-Games/GrainByGrain) | Get rid of a tunnel's worth of sand in a prison yard, one trouser leg at a time. |
| <img src="https://raw.githubusercontent.com/Lightened-Games/FlashCount/main/media/shot1.jpg" width="240"> | [**Flash Count**](https://github.com/Lightened-Games/FlashCount) | Hunt tanks you can't see by timing the gap between muzzle flash and boom. |
| <img src="https://raw.githubusercontent.com/Lightened-Games/SpringLoaded/main/media/shot1.jpg" width="240"> | [**Spring Loaded**](https://github.com/Lightened-Games/SpringLoaded) | Mech boxing where you can't punch: load the ropes, launch when the champion vents. |
| <img src="https://raw.githubusercontent.com/Lightened-Games/Wingtip/main/media/shot1.jpg" width="240"> | [**Wingtip**](https://github.com/Lightened-Games/Wingtip) | No guns: tip flying bombs off course with your wingtip, and choose where they fall. |

Each repository has the source, controls and screenshots. The full playable project is on its Releases page.
